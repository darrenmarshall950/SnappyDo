# LUT Packs (downloaded bulk-import sources)

Film-emulation LUTs in this directory were bulk-downloaded from
[YahiaAngelo/Film-Luts](https://github.com/YahiaAngelo/Film-Luts) on GitHub,
which mirrors the G'MIC film LUTs collection (MIT/CC license). 296 .cube
files across 9 categories — b&w, color slide, negative (modern/old),
instant (pro/consumer), print, Fuji X-Trans III.

These files are **not consumed at runtime** — they were downloaded to
populate SnappyDo's  table. Once uploaded, the originals can be
deleted if you want to reclaim disk space.
